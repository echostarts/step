# ТЗ — игра «ОТРЕЧЁННЫЕ» (v2, изометрия)

Браузерная пошаговая отрядная тактика-RPG в духе ранних Fallout / Jagged Alliance / XCOM, тёмное фэнтези, настоящее 3D с изометрической камерой. Оригинальное техзадание; статус выполнения — в [README](../README.md).

## Сеттинг и тон

Тёмное фэнтези. Земли выкошены Бледным Мором. Отряд из четырёх осуждённых — «отречённых» — получает отсрочку петли за грязную работу Серого Ордена: деревня Чернолесье третью неделю молчит, нужно выяснить почему. Тон — сухой, мрачный, без пафоса; редкая чёрная ирония в духе Planescape: Torment и Disco Elysium. Никаких реальных религий и копирайтных вселенных.

## Стек и архитектура

- Vite + TypeScript + Three.js (npm). Без игровых движков поверх, без React.
- Камера ортографическая, классический изометрический угол; поворот сцены на 90° клавишами Q/E (4 фиксированных ракурса), зум колесом/пинчем.
- Логика боя — на квадратной сетке, полностью отделена от рендера и детерминирована; ГПСЧ сидируемый (seed в URL).
- Контент отделён от кода: юниты, предметы, перки, диалоги, карты — типизированные data-файлы.
- Все игровые строки через словарь ключей (i18n-ready), язык контента — русский.
- Состояние сериализуемо: сейв/лоад в localStorage + экспорт/импорт строкой.

## Ассеты

KayKit (CC0): Dungeon Remastered, Character Pack Adventurers, Character Pack Skeletons, Character Animations. Иконки: game-icons.net (CC BY 3.0, обязательная атрибуция в титрах). Шрифт: готический с Google Fonts через @fontsource (OFL). Звук — только синтез WebAudio.

## Кор: тактический бой

Квадратная сетка до ~48×32; движение 4-направленное, 1 ОД за клетку. Пул ОД база 8 (модифицируется Ловкостью). Стоимости: лёгкая атака 3, тяжёлая 5, перезарядка арбалета 2, предмет 4, дверь 1, передача предмета 2, пас копит до +2 ОД. Инициатива по Ловкости. LOS лучом по сетке. Укрытия: полу −20, полное −40, фланг снимает. Шанс попадания показывается до атаки. Крит ×2. Броня — плоское поглощение. AoE-огонь 3×3 с поджогом на 2 хода. Статусы: кровотечение, горение, оглушение. 0 HP бойца = без сознания; после победы — травма. Поражение = весь отряд лёг.

## RPG-система

Статы 1–10: Сила, Ловкость, Воля, Разум. Опыт за бои и диалоги равноценно. Уровень: +1 стат и перк из трёх. Перков 12, ни один не плоский бонус. Отряд: Вдова (арбалет), Расстрига (алхимия), Колодник (ближний бой), Книжница (метательное, знания).

## Инвентарь

Слоты: основное, запасное, броня, амулет, 4 быстрых. Общий рюкзак с лимитом веса от суммарной Силы. ≥15 предметов, 6 оружий с разными глаголами, смена оружия видна на модели. Тултипы.

## Диалоги и сюжет

Data-driven диалоги: условия, чеки статов, последствия. Пролог 30–45 минут: Чернолесье → 3 NPC → реликвия в часовне. Бой 1 обучающий, Бой 2 можно избежать/ослабить, финал — три выбора и три эпилога.

## ИИ врагов

КА: раненые > фланг > ближайший; правило укрытия; резервирование клеток; алхимик кидает огонь по скоплению; мораль при гибели вожака.
